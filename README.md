## 🚀 How to Run the Programs Locally

1. **Clone this repository:**
   ```bash
   git clone https://github.com/dipeshbhatt000/C-programming-course
   cd C-programming-course
   ```

2. **Navigate to any specific Chapter or Practice Set folder:**
   ```bash
   cd Chapter_04_Practice
   ```

3. **Compile the program using GCC:**
   ```bash
   gcc 01_multiplication_table.c -o table
   ```

4. **Run the executable file:**
   * **Windows:** `table.exe`
   * **Mac/Linux:** `./table`
